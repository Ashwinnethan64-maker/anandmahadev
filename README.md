### 🔬 [Study-Aware Prompt Builder](https://github.com/anandmahadev/study-aware-prompt-builder)
> *Methodology-aware Python framework for reproducible AI-assisted UX research.*

Built as a foundational prototype for **RUXAILAB (GSoC)**. Generates, manages, and validates LLM prompts for UX research with scientific rigor and audit trails.

- **Audit Hash System** — SHA-256 trace hashes per prompt for research reproducibility
- **Framework Safety** — Custom exception hierarchies (`MissingParameterError`, `TemplateLoadError`) to gracefully halt bad data
- **CLI Interface** — `argparse`-powered shell utility for data-science workflows
- **High Throughput** — ~4,668 ops/sec with ~0.214ms average latency
- **Zero Dependencies** — Python standard library only
